# doppelganger

**Work in progress.**

ML synth sound-matching for Ableton Live's **Operator** — feed in an audio sample and get
the closest-matching Operator preset (inspired by Synplant 2's Genopatch, using the real
Ableton Operator, not a clone). Uses the new Ableton Live 12 Extensions Beta feature released a few days ago

Monkey business going on in the **[`dev`](https://github.com/FugueStates/doppelganger/tree/dev)** branch.
