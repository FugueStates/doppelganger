# doppelganger

🚧 **Work in progress.**

ML synth sound-matching for Ableton Live's **Operator** — feed in an audio sample and get
the closest-matching Operator preset (inspired by Synplant 2's Genopatch, using the real
Ableton Operator, not a clone).

Active development is on the **[`dev`](https://github.com/FugueStates/doppelganger/tree/dev)** branch.
